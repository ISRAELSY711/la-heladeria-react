
# La Heladería

Proyecto académico de desarrollo web para administrar el menú de una heladería, construido progresivamente con React.

## Descripción

La aplicación permitirá gestionar los sabores disponibles de una heladería, mostrando información como:

- Nombre del sabor.
- Imagen.
- Descripción.
- Precio.
- Unidades disponibles en stock.

## Objetivo

Desarrollar una aplicación web comprendiendo progresivamente los fundamentos de React, desde la creación de elementos hasta la construcción de una aplicación interactiva y accesible.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- React
- React DOM

## Referencia bibliográfica

**React sin magia: del elemento a la aplicación accesible**
